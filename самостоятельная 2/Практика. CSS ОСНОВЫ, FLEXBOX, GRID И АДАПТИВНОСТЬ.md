### 3. Требования к каждой секции

#### 1. Header

- **Flexbox:** логотип слева, навигация справа.
- `justify-content: space-between`, `align-items: center`.
- Hover-эффекты на ссылках.
- Sticky-позиционирование.

#### 2. Hero

- **Flexbox:** центрирование контента.
- `flex-direction: column`, `justify-content: center`, `align-items: center`.
- Фоновое изображение или градиент.
  - Кнопка CTA с hover-эффектом.
- Минимальная высота — `70vh`.

#### 3. О школе

- **Flexbox:** текст слева, изображение справа.
- Отступы через `gap`.
- На мобильных — переход в столбец.
- Заголовок, 2 абзаца текста, список преимуществ.

#### 4. Преимущества

- **Flexbox:** 4 карточки в ряд.
- `flex-wrap: wrap`, `gap`.
- Каждая карточка: иконка, заголовок, описание.
- Hover-эффект: подъём.

#### 5. Курсы

- **Flexbox:** 6 карточек в ряд с переносом.
- `flex-wrap: wrap`, `gap`.
- Каждая карточка: изображение, заголовок, описание, цена, кнопка.
- Hover-эффект: подъём + усиление тени.

#### 6. Преподаватели

- **Flexbox:** 4 карточки в ряд.
- Каждая карточка: фото, имя, должность, краткое описание.
- Hover-эффект: изменение цвета имени.

#### 7. Отзывы

- **Flexbox:** 3 отзыва в ряд.
- `flex-wrap: wrap`, `gap`.
- Каждый отзыв: аватар, имя, текст, рейтинг (звёзды).
- На мобильных — в столбец.

#### 8. FAQ

- 5 вопросов-ответов.
- Каждый вопрос — в отдельном блоке.
- Использовать `<details>` и `<summary>` для раскрытия.
- Стилизация через CSS.

#### 9. Контакты

- **Flexbox:** форма слева, контактная информация справа.
- Форма: имя, email, сообщение, кнопка.
- Контактная информация: адрес, телефон, email, соцсети.
- На мобильных — в столбец.

#### 10. Footer

- **Flexbox:** 4 колонки.
- `justify-content: space-between`.
- Колонки: о школе, курсы, контакты, соцсети.
- Копирайт внизу.
- На мобильных — в столбец.

### 4. Требования к CSS

#### Селекторы (обязательно)

Использовать:

- Селекторы по тегу.
- Селекторы по классу.
- Селектор по id (минимум 1).
- Комбинированные селекторы.
- Псевдоклассы (`:hover`, `:focus`).

#### Box-model

- Все элементы — `box-sizing: border-box`.
- Отступы через `padding` и `margin`.
- Использовать `gap` в Flexbox.

#### Flexbox (обязательно)

Использовать минимум 8 раз:

- Header.
- Hero.
- О школе.
- Преимущества.
- Курсы.
- Преподаватели.
- Отзывы.
- Контакты.
- Footer.

#### Адаптивность (обязательно)

- **Mobile-first** подход.
- Минимум 3 media queries:
  - `@media (min-width: 768px)` — планшет.
  - `@media (min-width: 1024px)` — ноутбук.
  - `@media (min-width: 1200px)` — десктоп.
- Метатег viewport.

#### Дополнительно

- Hover-эффекты.
- Плавные переходы (`transition`).
- Скругления (`border-radius`).
- Тени (`box-shadow`).
